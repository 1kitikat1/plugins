# Плагины лаунчера Nemesis

Магазин плагинов для лаунчера Nemesis. Лаунчер читает каталог `catalog.json`
из этого репозитория и показывает плагины в разделе **«Плагины → Магазин»** —
оттуда их можно скачать одним нажатием.

## Как установить плагин вручную

Скачай jar из папки `jars/` и положи его в папку плагинов:

- переносная сборка: `<папка с NemesisLauncher.exe>/plugins`
- установка: `%LOCALAPPDATA%\NemesisLauncher\plugins`

Затем в лаунчере: **Плагины → «Перезагрузить плагины»**.

## Плагины

- **Аниме-пак** (`anime-pack`) — милые иконки меню вместо штриховых:
  цветок сакуры, котик, лапка, сердечко и искра для раздела плагинов.
- **Цвет из фона** (`theme-from-background`) — главный цвет берётся из текущих
  обоев, весь лаунчер перекрашивается под него; сам обновляется при смене фона.
- **Синтвейв** (`synthwave`) — ретро-фон с неоновым солнцем и перспективной
  сеткой, ярко-розовый акцент.
- **Минимал** (`minimal`) — чистый графит с мягким свечением и сдержанный
  тёплый акцент.

## Структура каталога

- `catalog.json` — список плагинов для магазина (имя, версия, описание,
  пути к jar и иконке);
- `jars/` — сами плагины;
- `icons/` — иконки 96×96 (`<id>.png`) для карточек магазина;
- `src/` — исходники всех плагинов.

## Как добавить свой плагин в магазин

1. Собери jar с атрибутом манифеста `Nemesis-Plugin-Class: <класс>`;
2. класс реализует `usa.kitikat.plugin.LauncherPlugin` (лаунчер даёт
   `setAccent`, `setBackground`, `setIconProvider` и другие хуки);
3. положи jar в `jars/`, иконку 96×96 в `icons/<id>.png`;
4. добавь запись в `catalog.json` (id, имя, версия, описание, jar, icon);
5. запусти — лаунчер подхватит каталог при открытии «Магазина».
